# rmcloud-go

A Go client for the reMarkable cloud sync protocol (sync v3 and v4): device registration, the root pointer and its indexes, blob download and
upload, and the notification socket.

The module speaks the protocol and nothing more. It does not choose a filesystem layout, a credential store or a user interface: secrets come in
through a store the caller provides, and every answer is one of this package's own types. Tests never call remarkable.com.

The command-line client **[rmctl](https://github.com/altessa-s/rmctl)** is built on it.

Part of **[Slate Drive](https://slatedrive.app)** ([repository](https://github.com/altessa-s/slatedrive)), the macOS app that shows a reMarkable
library in Finder.

## Requirements

Go 1.27 or newer: the module uses generic methods, `encoding/json/v2`, `testing/synctest` and the `uuid` package. `go.mod` and `devtools/go.mod`
pin the `go1.27.3` toolchain; with the default `GOTOOLCHAIN=auto`, an older 1.27 fetches it on the first `go` command.

It is built on these altessa-s modules:

| Module | What this client takes from it |
|---|---|
| [go-atlas-core](https://github.com/altessa-s/go-atlas-core) | `retry` loop and backoff, `time/clock`, `runtime/singleflight`, `types/redacted` for tokens, `errors` canonical sentinels and `errors/network`, `runtime/leakcheck` in tests |
| [go-atlas-net](https://github.com/altessa-s/go-atlas-net) | `http/client`: pooled transports, a circuit breaker per host, redacted transport errors, the SSRF guard |
| [go-tlsutils](https://github.com/altessa-s/go-tlsutils) | the client TLS baseline: TLS 1.2 or later with curated cipher suites |
| [go-optgen](https://github.com/altessa-s/go-optgen) | every `With` option, generated into `options_gen.go` (a dev tool pinned in `devtools/go.mod`) |

## Usage

`New(store, opts...)` does no I/O and takes no context; the secret store is its one required argument, and a nil store is an error. `Close` stops
the notification stream and releases idle connections.

The store holds three secrets under fixed names (`SecretDeviceToken`, `SecretDeviceID`, `SecretUserToken`) through `Secret`, `Save` and
`Forget`. A device is registered once with the eight-character code the account holder reads at `RegistrationPage()`.

| Option | Default | Effect |
|---|---|---|
| `WithEndpoints` | `Production()` | The auth host and the configured sync host. Token calls always use them. |
| `WithResolver` | discovery | Replaces host choice for sync and notifications. A nil resolver is ignored. |
| `WithUserAgent` | the User-Agent the service expects | The User-Agent on every call. An empty string omits the header. |
| `WithDeviceDesc` | `DeviceDescMac` | The device description sent at registration. |
| `WithRoundTripper` | pooled transports | Routes every request, the notification upgrade included, through the caller's `http.RoundTripper`. |
| `WithRootCAs` | system pool | Trusts the caller's own authority for every call and the notification socket. |
| `WithLogger` | `slog.Default` | Where the client's records, the wire log included, go. |

A nil option is skipped. The options other than `WithUserAgent` are generated by go-optgen, so each ignores a nil or empty argument and keeps its
default.

### Hosts, transport and security

- With the production pair and no resolver, sync and notifications follow discovery (`discovery/v1/endpoints`), and the region named in the user
  token picks the sync host. Any other pair is used as given, with no discovery.
- `FromEnvironment` reads `RMCLOUD_HOST`, `RMCLOUD_AUTH_HOST` and `RMCLOUD_SYNC_HOST` from the map it is given and returns `(Endpoints, error)`:
  HTTPS is accepted anywhere and HTTP only on the loopback. A refused value leaves its host alone and is named in the error, never quoted.
- HTTP goes through go-atlas-net clients: a circuit breaker per host, and transport errors with their URLs and unknown messages redacted. The
  clients never retry; the protocol does, because only it knows which calls may repeat.
- No request has a deadline of its own; the caller's context is the only overall limit. What is bounded is a request that stopped moving:
  response headers that do not come within 60 s of the request being written (5 min after a file upload), a body read into memory that brings
  no byte for 45 s, and an HTTP/2 connection that leaves a ping unanswered, which is found in about 30 s. Each fails as a `*TransportError`
  (`ReasonTimedOut`, or `ReasonNetworkConnectionLost` for the ping) and is retried; a transfer that is slow but alive is never cut. A
  round tripper from `WithRoundTripper` keeps its own header wait and pings.
- A user token is judged in the server's time: the `iat` of each token bought shows how far the local clock stands from the server's, so a
  machine whose clock is hours off keeps and reuses its token. A difference past five minutes is logged as a warning.
- Against the production hosts the clients refuse to dial private and loopback addresses. Other endpoints, a resolver, or a round tripper turn
  that guard off, so a server on the caller's own network stays reachable. The notification socket has no guard of its own: its host is the
  configured one or one discovery published for a trusted reMarkable domain.
- Tokens are carried as `redacted.RedactedString` inside the module: fmt, slog and JSON print a placeholder. Their text leaves the redaction only
  for an `Authorization` header, the store, and the claims.
- `RMCLOUD_WIRE_LOG=headers` (or `bodies`) logs each exchange at debug level through the client's logger, with credentials masked and query
  strings dropped.

```go
func syncLibrary(ctx context.Context, store rmcloud.SecretStore, code string, log *slog.Logger) error {
    client, err := rmcloud.New(store, rmcloud.WithLogger(log))
    if err != nil {
        return err
    }
    defer client.Close()
    if err := client.RegisterDevice(ctx, code); err != nil {
        return err
    }
    _, index, err := client.RootIndex(ctx)
    if err != nil {
        return err
    }
    for _, entry := range index.Entries {
        if !entry.IsDocument() {
            continue
        }
        if _, err := client.Index(ctx, entry.Hash, entry.IndexName()); err != nil {
            return err
        }
    }
    return nil
}
```

Before an upload, `MissingFiles` asks which blobs the service does not hold yet, so the ones already there are not sent again:

```go
func uploadMissing(ctx context.Context, client *rmcloud.Client, files map[string][]byte) error {
    names := make(map[string]string, len(files))
    hashes := make([]string, 0, len(files))
    for name, body := range files {
        hash := rmcloud.BlobHash(body)
        names[hash] = name
        hashes = append(hashes, hash)
    }
    missing, err := client.MissingFiles(ctx, hashes)
    if err != nil {
        return err
    }
    for _, hash := range missing {
        name := names[hash]
        if _, err := client.Upload(ctx, files[name], name); err != nil {
            return err
        }
    }
    return nil
}
```

## API

Every call that reaches the service takes a context and fails with one of the errors below.

| Area | API | Service call |
|---|---|---|
| Device | `RegisterDevice`, `IsRegistered`, `RevokeDevice`, `ForgetDevice`, `Plan` | `token/json/2/device/new`, `token/json/2/user/new`, `token/json/3/device/delete` |
| Root | `Root`, `RootIndex`, `PutRoot` | `GET sync/v4/root` (falls back to v3), `PUT sync/v3/root` |
| Blobs | `Blob`, `BlobFile`, `Index`, `Upload`, `UploadFile`, `MissingFiles` | `sync/v3/files/{hash}`, `POST sync/v3/check-files` |
| Notifications | `StartNotifications`, `StopNotifications` | `wss notifications/ws/json/1` |
| Hosts | `WithResolver`, `WithEndpoints`, `FromEnvironment` | `discovery/v1/endpoints` |

Reads check the bytes against the hash they were asked for. Responses are decoded strictly with `encoding/json/v2`: a body with a duplicate key,
invalid UTF-8, or a field name in another case is a `*MalformedResponseError`.

A 409 or 412 on `PutRoot` is `KindRootConflict`: the caller re-reads and rebuilds. `PutRoot` repeats a rate limit and nothing else, since a write
that may have landed is not sent again blind. The other calls retry 5xx, network failures and rate limits on go-atlas-core's retry loop (three
attempts from 300 ms, growing threefold to a 20 s ceiling, up to a fifth added as jitter; a server's `Retry-After` wins), and fetch a fresh user
token once on a 401. A body cut short is a lost connection (`ReasonNetworkConnectionLost`) and is retried like one, and so is a
request that stopped moving (`ReasonTimedOut`); the caller's own cancellation or deadline is returned as it is and never retried. An open circuit breaker
(`ReasonCircuitOpen`), a dial the SSRF guard refused (`ReasonBlocked`), and a failed TLS handshake such as an untrusted certificate
(`ReasonSecureConnectionFailed`) are not retried. Concurrent callers share one user-token exchange and one discovery call.

`StartNotifications` delivers each `Notification` to a callback. Its `Kind` is `NotificationConnected` (again after every reconnect),
`NotificationEvent` (with `SyncComplete`, `Name`, `DocumentID`, `VisibleName`, `FromThisDevice` and the raw `Frame`), `NotificationUnreadable`
(a frame that did not parse, with its `Frame`), or `NotificationDropped` (with `Err`; a socket that cannot reach its host drops with a
`*TransportError`). An unreadable frame is still a sign that the account changed.

The index format is public too: `Parse`, `DecodeIndex(data, expected)`, `SerializeRoot`, `SerializeDocument`, `NodeHash`, `BlobHash`,
`FileHash(ctx, path)` and `GoogHash`. An `Index` carries `Declared`, the count a v4 file names on its count line, and `CountMismatch` reports a
file that disagrees with itself. `Entry.IsDocument` decides by the record's name, since either type value can mark a document.

The public types are aliases of the module's internal protocol types; `go doc` on each alias lists its fields and methods.

## Errors

`Error` is an interface with `Kind()`, and the set of kinds is closed:

- The kinds without a payload are sentinels matched with `errors.Is`: `ErrNotRegistered`, `ErrInvalidOneTimeCode`, `ErrUnauthorized`,
  `ErrAccountWithoutTablet`, `ErrNoRootYet`.
- Every other kind is its own type, recovered with `errors.As`: `*HTTPError`, `*HashMismatchError`, `*RateLimitedError`, `*RootConflictError`,
  `*TransportError`, `*MalformedIndexError`, `*MalformedResponseError`, `*MissingHashError`, `*NotOnThisPlanError`, `*WriteRejectedError`,
  `*UnsupportedSchemaError`, `*UnsupportedPlatformError`, `*NothingToAskError`, `*OversizedResponseError`.
- `KindOf` and `IsKind` name the case of any error in a chain. `IsDocumentUnavailable` reports an error about the object asked for (a 404, or
  bytes that are not a readable index or do not match their hash) rather than the request. `IsHostUnreachable` reports a transport failure whose
  host could not be found or reached.
- A `*TransportError` carries a `TransportReason`: `ReasonTimedOut`, `ReasonCannotFindHost`, `ReasonCannotConnectToHost`,
  `ReasonNetworkConnectionLost`, `ReasonDNSLookupFailed`, `ReasonNotConnectedToInternet`, `ReasonSecureConnectionFailed`, `ReasonCircuitOpen`,
  `ReasonBlocked`.
- Each error also matches its go-atlas-core canonical error: transport failures, rate limits and 5xx are `errors.ErrUnavailable`, a root
  conflict is `ErrConflict`, a 404 or a missing root is `ErrNotFound`, a refused code is `ErrInvalidArgument`, and a missing registration, plan
  or platform facility is `ErrFailedPrecondition`.

`coreerrors` is `github.com/altessa-s/go-atlas-core/errors`:

```go
switch {
case errors.Is(err, coreerrors.ErrUnavailable):
    // a transport failure, a rate limit, or a 5xx: try again later
case errors.Is(err, rmcloud.ErrNotRegistered):
    // ask for a one-time code
case rmcloud.IsKind(err, rmcloud.KindRootConflict):
    // re-read the root and rebuild
default:
    if status, ok := errors.AsType[*rmcloud.HTTPError](err); ok {
        log.Printf("status %d on %s", status.Status, status.Path)
    }
}
```

Go does not check that a switch on `Kind` is exhaustive; enable the exhaustive linter to have a new kind break the build rather than fall
through.

## Architecture

The module follows Clean Architecture: dependencies point inward, and every boundary is an interface in `internal/port`.

```
rmcloud (facade) ──► internal/wiring ──► internal/app/*     ──► internal/port ──► internal/domain
       │                    └──────────► internal/adapter/* ──► internal/port, internal/domain
       └──► internal/port, internal/domain
```

An arrow is an import. No use case imports an adapter and no adapter imports a use case; the composition root hands each use case its adapters
through the ports.

**Facade**

- `rmcloud` — reads the options, calls `wiring.Build`, and holds the use cases only as ports. Imports nothing internal but
  `domain`, `port` and `wiring`.

**Entities and ports**

- `internal/domain` — the protocol's types: index parsing and serialization, hashes, endpoints, claims, the closed error set and its
  HTTP status mapping. No I/O, no logging, no network.
- `internal/port` — contracts only: the driven ports (HTTP exchange, socket, secret store, files, hosts, tokens), the use cases' input
  ports (`SyncStore`, `Account`, `NotificationStream`) and the notification output (`Event`, `Signal`). Time is go-atlas-core's
  `clock.Clock`.

**Use cases**

- `internal/app/auth` — device registration and the user-token lifecycle.
- `internal/app/syncstore` — sync reads and writes.
- `internal/app/notify` — the notification stream: reconnects, keepalive, parsing.
- `internal/app/discovery` — host choice: region, discovery, demotion.
- `internal/app/retry` — which protocol errors repeat, on go-atlas-core's retry loop.

**Adapters**

- `internal/adapter/httpapi` — HTTP on go-atlas-net with go-tlsutils TLS, the redirect policy, the wire log.
- `internal/adapter/ws` — the WebSocket dialer.
- `internal/adapter/fs` — local files and the macOS version for the User-Agent.
- `internal/adapter/neterr` — names a network failure as a protocol error, for `httpapi` and `ws`.

**Composition root and tests**

- `internal/wiring` — the one package that knows every adapter and use case and connects them.
- `internal/porttest`, `internal/domaintest` — doubles of the ports and protocol-error comparison.

The rules are enforced twice. `architecture_test.go` checks each package's imports, keeps go-atlas-net and go-tlsutils out of `domain`, `port`,
and the use cases, and holds the facade to `domain`, `port`, and `wiring`. `depguard` in `.golangci.yml` keeps the same lines and the test
doubles out of production code.

Each package keeps its tunables in a private `options` struct with go-optgen tags (`options.go`, generated `options_gen.go`) and takes its
required dependencies as constructor arguments. Every internal package has a `doc.go` and a `README.md`.

### Tests

A test that needs the network, the secret store, or the clock takes a double from `porttest` instead. A package whose tests start goroutines ends its test binary with the leak check:

```go
func TestMain(m *testing.M) {
	code := m.Run()
	if code == 0 {
		if err := leakcheck.Check(); err != nil {
			fmt.Fprintln(os.Stderr, err)
			code = 1
		}
	}
	os.Exit(code)
}
```

Time in tests is `porttest.Clock`, which records each sleep over go-atlas-core's `clock.Fake`, or the real clock inside a `testing/synctest` bubble. `depguard` keeps `porttest` and `domaintest` out of production code. `example_test.go` holds the runnable examples; `go doc` shows them, and `go test` checks their output.
